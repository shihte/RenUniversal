Hot-Pluggable Skills

熱插拔技能架構

ActionEngine 於運行時會動態反射式掃描 skills/ 目錄下的判定包。開發者只需依照 JSON 配置規則新增目錄，無需重寫或重新編譯核心框架，即可為系統擴充全新的身體動作特徵判定技能。

# skills/lean/config.json { "name": "lean_detection", "version": "1.0", "landmarks": [11, 12], "threshold": 0.08, "hysteresis": 0.02, "event": "LEAN_DETECTED" } # ActionEngine 自動偵測並載入 ↑ ❯ make run ✓ Loaded: lean_detection v1.0 ✓ Loaded: squat_detection v2.1 ✓ Loaded: chin_tuck v1.3
# events/jump_event.py class JumpEvent(BaseEvent): def evaluate(self, state): # 高階組合：squat → stand squat = state["squat_detection"] stand = state["stand_detection"] if self.prev == squat and stand: return Event("JUMP") self.prev = squat
Event Decoupling

高階事件組合

底層偵測到的單一動作特徵，會被傳遞給 Event Engine 進行高階邏輯判定。這種底層「特徵」與高層「事件」解耦的設計，讓系統不再侷限於單一復健動作，可以任意組合多個特徵來觸發複雜的互動事件。
