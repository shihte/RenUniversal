一鍵安裝框架

開發者只需將遊戲打包成資料夾，附帶 .renuniversal 宣告檔，系統便會自動解析並將所有 Skills、Events 與 App 安裝至核心引擎目錄。

Mac / Linux make install PATH=../AppleCatch
Windows renuniversal.bat install ..\AppleCatch
# .renuniversal — 外掛宣告檔 { "name": "AppleCatch", "version": "1.0", "author": "community", "skills": [ "skills/lean" ], "events": [ "events/tilt_event" ], "apps": [ "apps/apple_catch.html" ] } ❯ make install PATH=../AppleCatch ✓ Plugin registered ✓ Hot-reloaded — ready!
# 打包自己的外掛 (Mac/Linux) ❯ make build \ NAME=MyGame \ SKILLS="skills/lean skills/squat" \ EVENTS="events/jump_event" \ APPS="web/apps/mygame.html" ✓ Built: dist/MyGame/ ✓ .renuniversal generated ✓ Ready to share on GitHub! # Windows ❯ renuniversal.bat build ^ --name MyGame ^ --skills skills\lean ^ --apps web\apps\mygame.html
