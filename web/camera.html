相機設定 (Camera Settings)

配置輸入來源、連線與隱私偏好。

鏡頭輸入來源 (Camera Source)

選擇目前啟用的鏡頭輸入。

多鏡頭模式會自動分割畫面。若使用手機串流，請掃描下方 QR Code 連線。

手機連線選項 (Mobile Connection Options)

掃描下方 QR Code，將您的手機作為外部鏡頭串流裝置連線。

區域網路 (Local Wi-Fi) 推薦使用 (Recommended)

手機與電腦需在同一 Wi-Fi 網域。掃描後點擊下方按鈕切換來源。

區域網路未開放 (Local Network Offline) 伺服器僅綁定本機。請使用以下指令重啟：
make start ARGS="--host 0.0.0.0"
遠端隧道 (Remote Tunnel)

適用於 4G/5G 行動網路環境。透過中繼伺服器會有些微延遲。

遠端隧道未啟用 (Tunnel Offline) 遠端隧道服務已關閉。請使用以下指令重啟：
make start ARGS="--enable-tunnel"

支援 AND / OR / NOT 等運算符。
