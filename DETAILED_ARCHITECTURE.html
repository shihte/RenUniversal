System Architecture

系統拓撲、邊緣狀態隔離層，以及動態幾何規則引擎的精確規範與設計模式。

System Topology

RenUniversal 採用單向數據流與邊緣運算設計。影像從本地鏡頭或手機串流輸入 Agent Pipeline 進行 30FPS 的採樣，經由 MediaPipe 提取特徵後，傳送至 Action Judgment Engine。

判定引擎會動態掃描 skills/ 目錄下的規則模組，評估異常狀態，並將結果寫入 Shared State。最終由 Flask Web 渲染層或 iOS 原生視圖呈現。

幾何運算元 (Next-Gen Operators)

無論是 iOS 或 Web 介面，新版引擎支援高級幾何運算，直接處理點與點之間的空間變化：

  • 變長 / 變短 (>, <)：計算兩點間距離是否大於或小於校準基準值的特定百分比。
  • 動態狀態偏移 (><)：只要兩點間的距離相較於校準時「變長或變短」超過閥值，即觸發偏移警報。
  • 雙獨立球體越界 (~~)：系統記住兩點在校準時的「絕對空間座標」，並為兩端點各自畫出物理級別的圓形防護網。任一端點飄出專屬防護圈時觸發，完美解決代償動作盲區。

數學特徵模型 (Math Models)

低頭比例 (Nose-Chin Ratio)

基於 3D 面部網格在投影面上的長度變化。當頭部前傾時，鼻尖與下巴底端在影像上的垂直距離會縮短。

// d_nose-chin = y_chin - y_nose
// Ratio is negative when looking down
Ratio = (d_nose-chin - baseline_d) / baseline_d

軀幹搖晃比 (Torso Sway)

以肩膀中點相對於影像寬度的偏離值來衡量水平位移。偏離基準越遠數值越高。

// Center_S = (Shoulder_L + Shoulder_R) / 2
Sway = abs(x_Center_S - x_baseline) / Frame_Width

設計模式與代碼映射

系統底層採用了大量經典的設計模式以維持高度的靈活性與執行緒安全：

  • Pipeline Pattern：pipeline.py 負責核心流水線驅動與影像特徵提取。
  • Plugin Pattern：action_engine.py 負責於運行時動態發現與載入 /skills/ 動作包。
  • State Pattern：state.py 提供跨執行緒安全的狀態同步與持久化讀寫。
  • Strategy Pattern：iOS 原生端的 RuleEngine.swift 負責實作 ~~ 與 >< 等進階空間策略。
