熱插拔外掛生態

打包 .renuniversal 模組。使用 make install 即可在免重啟的情況下注入全新的體感遊戲或判定邏輯。

# 1. Clone the repository
~ $ git clone https://github.com/shihte/RenUniversal.git
# 2. Setup and run edge server (Mac/Linux)
~ $ make setup
~ $ make start ARGS="--host 0.0.0.0 --enable-tunnel"
# 3. Hot-install a 3rd party plugin
~ $ make install PATH=../AppleCatchGame
✓ Plugin successfully registered and hot-reloaded!
