iOS Native Experience

為了實現「零門檻阿公級部署」，我們徹底打破網頁版的效能天花板，將整個系統封裝進 iOS 原生應用中。

100% Neural Engine 算力

完全拋棄瀏覽器 WebGL 與伺服器連線的束縛。底層透過 Swift 封裝 Google MediaPipe C++ 核心，直接調用 Apple 內建的硬體神經網路引擎。即使在舊款 iPhone 上，也能實現極低發熱與 60 FPS 滿血無延遲的骨架捕捉。

視覺化拓樸選點系統

告別過去需要查表尋找代號 (如 p11, f152) 的痛苦體驗。我們開發了 PointReferenceView 互動選擇器，支援如同 Apple Maps 般的雙指縮放與拖曳，只需輕觸螢幕，即可從 500+ 個精密特徵點中直接指定監控目標。

Geometric Rule Engine

摒棄傳統的硬編碼，導入動態熱插拔的物理特徵數學評估演算法。

雙獨立球體越界判定 (~~)

傳統的距離判定容易在代償動作中出現盲區（例如身體整體平移）。我們獨創了 `~~` 運算元，系統會為指定節點各自繪製絕對空間的防護圈，只要任一端點飄出，即刻觸發飆紅警告。同時自動校正不同裝置的長寬比誤差，實現像素級精準。

動態狀態偏移 (><)

除了靜態的變長或變短 ( `<` , `>` ) 限制外，系統支援偵測相對位移變化量。透過預校準，只要監控距離超過閥值上限或下限，立即捕捉異狀。內建磁滯抗噪濾波器 (Hysteresis Filter)，徹底杜絕高頻抖動誤報。

硬體層級隱私打碼

為保護患者與使用者隱私，我們在影像處理最底層實作了即時抹除機制。精準擷取輪廓並向外延伸 150%，覆蓋五官、邊緣與特徵，但完全不干擾其上方疊加的 AI 點位與幾何判定。

Agentic Plugin System

除了手機端，我們的 Python 邊緣伺服器提供了強大的第三方外掛擴充能力。

多相機無縫融合陣列

後端伺服器支援同時連線多支 UVC 網路攝影機或手機 QR Code 串流。底層 AI 流水線會並行掃描所有畫面，自動標定含有最完整人體或臉部特徵的鏡頭源進行融合切換，達到真正意義上的零死角空間追蹤。

第三方 .renuniversal 封裝

任何人都可以開發專屬的體感遊戲或判定邏輯。將 `skills/` 與 `events/` 打包，透過我們提供的工具即可生成單一安裝檔。使用終端機指令 `make install` 即可將新外掛熱載入至核心引擎中，擴展出深蹲檢測、平衡遊戲等多元應用。
