Build from Source

身為開源專案，您可以直接透過 Xcode 將其編譯並安裝至實體設備，無需任何越獄步驟。

🍏

需求條件

需準備 Mac 電腦、最新版 Xcode，以及 iOS 15.0+ 的 iPhone 或 iPad 實體機。

🔑

免費開發者簽名

在 Xcode 的 Signing 頁籤登入個人 Apple ID 即可進行 7 天免付費簽名部署。

⚠️

重要注意事項

請務必開啟 RenUniversal.xcworkspace 而非 xcodeproj，因為本專案使用 CocoaPods 管理底層的 C++ 依賴。

# 1. Clone & Enter Directory
~ $ git clone https://github.com/shihte/RenUniversal.git
~ $ cd RenUniversal/RenUniversal
# 2. Open Workspace in Xcode
~ $ open RenUniversal.xcworkspace
# 3. Build & Run
In Xcode, select your device, configure signing, and press ⌘R.
